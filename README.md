# portfolio2
🎵 바이브 코딩 (Vibe Coding) - 음악 리듬에 맞춰 배우는 C 프로그래밍

## 📌 프로젝트 개요

**바이브 코딩**은 음악의 비트와 리듬에 맞춰 코드를 작성하고 실행하는 창의적인 프로그래밍 방식입니다. 이 프로젝트는 고등학생을 위한 C언어 학습 교재로, 구조체, 배열, 함수, 파일 입출력 등 프로그래밍의 핵심 개념을 음악이라는 흥미로운 주제로 배울 수 있습니다.

## 📚 소스코드 상세 설명

### `vibe_coding_example.c`

#### 1️⃣ **데이터 구조**

```c
// 🎶 비트(Beat) 구조체 - 음악의 한 박자를 나타냄
typedef struct {
    int beat_number;      // 비트 번호 (1, 2, 3, 4...)
    char* note;           // 음표 (도, 레, 미...)
    int duration;         // 지속 시간 (밀리초)
    int intensity;        // 강도 (1~10, ●의 개수로 표시)
} Beat;

// 🎼 곡(Song) 구조체 - 전체 곡을 나타냄
typedef struct {
    char* title;          // 곡의 제목
    int tempo;            // 분당 박자 수 (BPM)
    Beat* beats;          // 비트 배열
    int beat_count;       // 총 비트 개수
} Song;
```

#### 2️⃣ **핵심 함수들**

| 함수명 | 목적 | 주요 개념 |
|--------|------|---------|
| `print_beat(Beat b)` | 비트를 시각적으로 출력 | 구조체 매개변수, 반복문 |
| `print_song(Song s)` | 전체 곡을 보기좋게 표시 | 중첩 반복문, 포매팅 |
| `calculate_average_intensity(Song s)` | 곡의 평균 강도 계산 | 배열 순회, 형변환 |
| `count_note(Song s, char* target_note)` | 특정 음표의 개수 세기 | 문자열 비교(`strcmp`) |
| `remix_song(Song s)` | 비트를 역순으로 재생 (리믹스) | 역순 반복문 |
| `save_song_to_file(Song s, char* filename)` | 곡을 파일로 저장 | 파일 입출력 (`fopen`, `fprintf`, `fclose`) |

#### 3️⃣ **4가지 실습 예제**

**예제 1: 간단한 곡 만들기** (109~129줄)
- 곡 구조체 초기화
- 비트 배열 생성
- 곡 출력 함수 호출
- **학습 포인트**: 구조체 초기화, 배열 사용

**예제 2: 곡 분석하기** (132~159줄)
- 곡의 평균 강도 계산
- 특정 음표의 개수 세기
- **학습 포인트**: 반복문, 조건문, 데이터 분석

**예제 3: 리믹스 만들기** (162~182줄)
- 비트를 역순으로 재생
- 창의적인 함수 활용
- **학습 포인트**: 역순 접근, 함수 활용의 다양성

**예제 4: 곡을 파일에 저장하기** (185~204줄)
- 파일 생성 및 쓰기
- 에러 처리
- **학습 포인트**: 파일 입출력, 에러 처리

#### 4️⃣ **도전 과제** (207~216줄)

학생들이 스스로 구현해볼 수 있는 4가지 과제:
1. 5개 이상의 비트로 새로운 곡 만들기
2. 가장 강도가 높은 비트를 찾는 함수 만들기
3. 총 재생 시간을 계산하는 함수 만들기
4. 비트를 추가/삭제하는 함수 만들기
